Topic 1: Create and Open Workbooks

Keyboard shortcuts, templates, and multiple ways to find and open files

0 of 4 sections read0%
All sections read!

One of the quickest ways to do anything in Excel — or any other Office application — is to use keyboard shortcuts. For example, to create a new workbook you can use Ctrl+N and to open an existing workbook you can use Ctrl+O.

There are hundreds of keyboard shortcuts available and they genuinely save time. Do not underestimate the value of the shortcut! Many shortcuts are common across Office apps and work throughout the entire Microsoft Office Suite. Learning keyboard shortcuts removes the need to navigate through numerous ribbon commands just to do something simple.

Learn keyboard shortcuts, and you’ll take the guesswork out of finding how to do things like Print, whether it’s a Word document, an Excel document, or any other Office file you work with.

✅
Key insight
Many shortcuts are identical across all Microsoft Office applications. Learning them in Excel means you already know them in Word, PowerPoint, and Outlook too.

There are several ways to create a new workbook in Excel. The fastest is a keyboard shortcut, but you can also use the ribbon or Quick Access Toolbar.

Steps to create a new workbook

1
Press Ctrl+N, or select New on the Quick Access Toolbar (if it has been added), or go to File > New.
2
Select the type of workbook to create: either a blank workbook (the most common starting point) or a pre-built template, which comes with pre-designed content and formatting to save you significant setup time.
Figure 1: The Excel Backstage New screen — choose a blank workbook or browse pre-built templates
💡
Templates tip
Don’t overlook Excel’s built-in templates — there are ready-made options for budgets, calendars, invoices, project trackers, and more. They can save hours of setup time. Browse them via File > New.
📄
Create from an existing workbook
To base a new workbook on an existing file, use Ctrl+O or File > Open, locate the file, then right-click it and select Open a Copy. This creates a new unsaved copy without altering the original.

Start by pressing Ctrl+O or going to File > Open. Depending on where the workbook is stored, you have several options for finding and opening it:

1
Recent files: If the file appears in the Open screen, simply double-click it (or press Space then Enter). This is the fastest option for files you’ve worked with recently.
2
Workbooks list: Select the workbook listed under the Workbooks tab in the Open screen — the file opens immediately without any additional navigation.
3
Folders: Select a folder (or an online location like OneDrive) to navigate to where the file is stored, then select the file to open it.
4
This PC: Select This PC, choose from the recent folder list, or use the Navigate up one level arrow to move through the Windows file structure until you find your file.
5
Browse: Select Browse (or press Ctrl+F12) to open the classic Open dialog box. Locate the file, then double-click it or select it and click Open.
Figure 2: The File Open screen — use the Workbooks or Folders tabs to locate and open recent files
💡
Extra tip: Use Windows File Explorer
Press Win+E to open Windows File Explorer directly from anywhere on your computer. Find your Excel file, then double-click it (or press Space + Enter). Excel files open in Excel automatically — no need to open Excel first.

The big takeaway
Keyboard shortcuts work across all Microsoft Office applications. Mastering Ctrl+N, Ctrl+O, Ctrl+S, and Ctrl+P gives you power in every Office app you’ll ever use — not just Excel.

Topic 2: Explore the Excel Interface

Ribbon, Backstage view, key interface elements, and hidden gems

When you open Excel for the first time, you are prompted with a menu to either create a new file or open an existing file. This is called the Excel Start Screen. From here you can also access recently used files and pre-built templates.

Once a workbook — even a blank one — is open, the full application interface activates and the workbook area takes up most of the screen. Every part of this interface has a name and a purpose, and understanding each element will help you work more efficiently.

✅
Two essential terms to know from day one
Excel files are called workbooks. Each workbook contains one or more worksheets (the individual tabs at the bottom of the screen). These two terms are used constantly throughout this course — make sure you know the difference before moving forward.

The video below gives you a tour of the Excel interface, walking through each key element so you can see exactly where everything is located before we dig into each part in detail.

At the very top of the Excel window (below the title bar) is the ribbon — a wide toolbar that holds all of Excel’s commands, organized into labeled tabs. Think of the ribbon as the control center for everything you can do in Excel.

Each tab contains groups of related commands. For example, the Home tab holds the most commonly used formatting and editing tools, while the Insert tab holds everything you need to add objects to your worksheet.

Figure 3: The Excel ribbon — the Home tab is shown here with its command groups visible below the tab name
💡
How to find any command
Not sure which tab a command is on? Use the Search / Tell Me bar at the top of the window. Type what you want to do (e.g., "merge cells") and Excel will find the command for you — no ribbon hunting required.

Pattern to remember
Tab names describe what they contain. Insert inserts things. Formulas has formula tools. Data has data tools. When in doubt, the tab name is your first clue.

Clicking the File tab is different from clicking any other tab. Instead of showing a set of ribbon commands, it opens the Backstage view — a full-screen panel that gives you access to file-level operations: creating, opening, saving, printing, sharing, exporting, and managing workbook settings.

Think of Backstage view as the place you go to manage the workbook as a file, rather than working on its contents. Press Esc or click the back arrow to return to your worksheet at any time.

Controlling the ribbon display

If your screen is small or you need more space to view a large dataset, you can control how much of the ribbon is visible using the Ribbon Display Options button in the upper-right corner of the Title bar:

  • Auto-hide Ribbon — hides the ribbon entirely. Click at the top of the application or press Alt to temporarily show it.
  • Show Tabs — shows only the tab names, not the commands below them. Click any tab name to see its commands temporarily.
  • Show Tabs and Commands — the default setting. The full ribbon is always visible with all tabs and their commands displayed.
Figure 4: Ribbon Display Options — access these from the upper-right corner of Excel
🔔
Quick trick
Double-clicking any ribbon tab toggles the ribbon on and off. This is the fastest way to get more screen space when working with a large spreadsheet — and just as easy to bring it back.

Once a workbook is open, the full Excel interface is active. The image below labels every key element. Study it carefully — you’ll hear these terms throughout the course and in any Excel documentation you encounter.

Figure 5: The Excel interface with all key elements labeled

Here is what each labeled element does:

  • Quick Access Toolbar — The small toolbar above or below the ribbon in the upper-left corner. By default it shows AutoSave, Save, Undo, and Redo. You can customize it to add any command you use frequently.
  • Ribbon — The main command area at the top of the window, organized into tabs and groups (covered in detail in Section 02).
  • Name Box — The box on the far left below the ribbon that displays the address of the currently selected cell (e.g., A1). You can also click here and type any cell address to jump directly to that cell.
  • Formula Bar — The bar next to the Name Box that shows the contents of the selected cell. If the cell contains a formula, you’ll see the formula here. If it contains text or a number, you’ll see that value.
  • Active Cell — The currently selected cell, highlighted with a green border. This is where data will be entered when you start typing.
  • Column Numbers (Letters) — The gray header letters (A, B, C...) across the top of the worksheet that identify each column.
  • Row Numbers — The gray numbers (1, 2, 3...) down the left side of the worksheet that identify each row.
  • Worksheet Tab — The tabs at the very bottom of the screen showing the names of each worksheet in the workbook (Sheet1, Sheet2, etc.). Click the + icon to add a new worksheet.
✅
Jump to any cell instantly
Click the Name Box, type any cell address (like D47 or Z1000), and press Enter. Excel jumps directly to that cell — no scrolling required. This is especially useful in very large spreadsheets.
🔔
Also worth knowing
Scroll bars on the right side (vertical) and bottom (horizontal) let you navigate through a large worksheet. The View controls and Zoom slider in the bottom-right corner let you switch between Normal, Page Layout, and Page Break Preview, and zoom in or out on your data.

Excel has a few lesser-known features that are worth discovering early. None of these are required knowledge at this stage, but they can make your experience noticeably smoother.

  • Draw tab — Lets you annotate worksheets with a digital pen or stylus, convert hand-drawn ink to shapes, and even convert handwritten math equations into typed formulas. If the Draw tab isn’t visible on your ribbon, you can add it via File → Options → Customize Ribbon.
  • Search / Tell Me — The search bar in the center of the Title bar (it says “Tell me what you want to do”). Type any action or question and Excel will surface the right commands instantly. Great when you know what you want to do but can’t find where it lives.
  • Minimize, Restore, Close — The standard window controls (− ☐ ✕) in the upper-right corner of the Title bar manage the size of the Excel window.
  • Display Settings & Zoom — The three small view icons near the bottom-right of the screen let you switch between Normal view, Page Layout view, and Page Break Preview. The Zoom slider next to them lets you zoom in or out. Page Layout view is especially useful before printing.
⭐
Fun fact
On the Draw tab, you can change your cursor into a rainbow pen or a galaxy pen and annotate your spreadsheet in style. A small but delightful feature hidden in an otherwise very serious application.
