Topic 2: Explore the Excel Interface

Get comfortable with Excel’s layout, terminology, and navigation before building your first workbook.

When you open Excel for the first time, you are prompted with a menu to either create a new file or open an existing file. Once a workbook — even a blank one — is open, the full application interface activates.

✅
Good to know
Excel files are called workbooks. Each workbook contains one or more worksheets (the individual tabs at the bottom). Don’t mix these up — they come up constantly.

At the top of the application is the ribbon — a bar holding several tabs. Each tab groups related commands. The tab name hints at what’s inside.

TabWhat you’ll find there
FileOpens Backstage view — manage settings, save, print, export
HomeMost-used tools: clipboard, font, alignment, number formatting
InsertAdd objects: pictures, icons, charts, SmartArt
Page LayoutThemes, page setup, and sheet display options
FormulasCreate functions, define names, audit formulas
DataImport data, sort, filter, and use data tools
ReviewProofing, track changes, protection, accessibility
ViewManage views, zoom, arrange windows, macros
HelpExcel help, Microsoft support, learning resources
💡
Pattern to remember
When in doubt, look at the tab names first — they describe exactly what their tools do.

Clicking File opens the Backstage view — a full panel with New, Open, Save, Print, Share, Export. Think of it as behind the curtain. Press Esc or the back arrow to return.

Control ribbon visibility with Ribbon Display Options (upper-right of Title bar):

  • Auto-hide Ribbon — hides it entirely; press Alt to peek
  • Show Tabs — tab names only; click a tab to see commands
  • Show Tabs and Commands — the default; everything visible
🔔
Quick trick
Double-clicking any ribbon tab toggles it on and off — handy for more screen space.

Once a workbook is open, these elements become active:

  • Quick Access Toolbar — upper-left, above ribbon. AutoSave, Save, Undo, Redo by default.
  • Search / Tell Me — center of Title bar. Find commands or get help.
  • Name Box — below ribbon on left. Shows selected cell address (e.g., A1).
  • Formula Bar — next to Name Box. Shows cell contents or formula.
  • Sheet tabs — bottom of screen. Click + to add a sheet.
  • Scroll bars — vertical (right) and horizontal (bottom).
  • View controls & Zoom slider — bottom-right. Switch views; zoom in or out.
✅
Pro tip
Click the Name Box, type any cell address like D47, press Enter — jumps there instantly.
  • Draw tab — Annotate with a digital pen, convert ink to shapes or math. Add via File → Options → Customize Ribbon.
  • Minimize, Restore, Close — Standard window controls, upper-right corner.
  • Display Settings — Three view icons at bottom-right, useful before printing.
⭐
Fun fact
You can turn your cursor into a rainbow or galaxy pen on the Draw tab — a small delight in an otherwise very serious application.
