Topic 1: Enter and Edit Data

Typing, navigating, editing, and correcting cell contents

All sections read!

Entering data into Excel is straightforward: select a cell, start typing, and confirm your entry. The key is understanding how Excel handles data before you confirm it — what you type appears in both the cell and the Formula Bar, and you have full control until you press a completion key.

Basic steps to enter data

1
Open or create a workbook. You need an open workbook before you can enter data. Use Ctrl+N for a new blank workbook or Ctrl+O to open an existing one.
2
Select the cell where you want to enter data. Click on it, or navigate using the arrow keys. The selected cell is highlighted with a green border and its address appears in the Name Box.
3
Start typing. As you type, your text appears in the cell and in the Formula Bar above. Excel is in entry mode at this point — you haven't committed the data yet.
✅
What you can enter
Excel cells can hold text (labels, names, descriptions), numbers (values for calculations), dates and times, and formulas (which start with an = sign). You don't need to do anything special to indicate which type — Excel detects it automatically. Numbers align right by default; text aligns left.
💡
Column width
You'll probably want to adjust column widths and row heights as you add data — Excel cells don't automatically expand to fit long text. That skill is covered in the next module. For now, just be aware that your data is there even if it appears cut off.

After typing data into a cell, you need to complete the entry to confirm it. Excel gives you several ways to do this, each of which also moves your cursor to a different location. Choosing the right key can save a lot of time when entering large amounts of data.

KeyWhat it doesBest used when
EnterConfirms entry and moves cursor down one rowEntering data column by column
TabConfirms entry and moves cursor right one columnEntering data row by row across columns
Shift+TabConfirms entry and moves cursor left one columnMoving back to fix an entry in the previous cell
Arrow keysConfirms entry and moves cursor one cell in any directionFlexible navigation while entering data
Ctrl+EnterConfirms entry and stays in the same cellEntering data without moving the cursor
Click another cellConfirms entry and moves cursor to the clicked cellCommon but not considered best practice — slower and less precise
💡
Pro workflow tip
When entering data across a row (like filling in a table), use Tab to move right through each column. When you press Enter at the end of the row, Excel returns your cursor to the first column of the next row — right where you started tabbing from. This makes filling in tables very efficient.
🔔
The Enter button in the Formula Bar
Next to the formula bar you'll see a tick mark (✓) and an X. The tick mark is the Enter button — it confirms your entry but keeps the cursor in the same cell (same as Ctrl+Enter). The X is the Cancel button — it discards your entry without making any change.

You will frequently need to go back and change something you already typed. Excel provides several ways to edit cell contents, depending on whether you want to replace the entire entry or make a small change at a specific position within the text.

Edit cell contents

There are three main ways to edit a cell:

  • Click the cell once, then edit in the Formula Bar — Click the cell to select it, then click inside the Formula Bar and make your changes there. Good for seeing the full content of a cell with a long entry.
  • Double-click the cell — Places your cursor directly inside the cell at the position you clicked. This puts Excel into edit mode, letting you position your cursor exactly where you want within the text.
  • Press F2 — Pressing F2 with a cell selected enters edit mode with the cursor at the end of the cell content. A fast keyboard-only alternative to double-clicking.

Once in edit mode, you can use the arrow keys to move within the cell text, Backspace to delete characters to the left, and Delete to delete characters to the right. Use any completion key (Enter, Tab, etc.) when done.

Cancel a cell entry

If you've started typing and want to abandon the entry entirely without changing the cell:

  • Press Esc on your keyboard — the fastest method
  • Click the Cancel button (X) in the Formula Bar
⚠
Important distinction
If you click another cell while in the middle of an entry, Excel confirms the entry rather than cancelling it. This is a common source of accidental edits. Always use Esc if you want to abandon what you were typing.

Clear cell contents

There are two ways to clear the contents of a cell:

  • Select the cell and press the Delete key on your keyboard — this clears the contents but keeps the cell (and any formatting) in place
  • Right-click the cell and choose Clear Contents from the context menu
⚠
Critical warning: Delete vs. Clear Contents
There are two different Delete options in Excel's context menu. Clear Contents removes only the data from the cell and leaves the cell itself in place. Delete (also in the context menu) removes the entire cell and shifts surrounding cells to fill the gap — which can completely disrupt the layout of your worksheet. Always use Clear Contents or the keyboard Delete key unless you specifically want to remove a cell and shift data.

Undo and Redo

Excel keeps a history of your recent actions and lets you reverse or restore them:

ActionShortcutButton location
Undo — reverse your last actionCtrl+ZQuick Access Toolbar (curved arrow left)
Redo — restore an action you undidCtrl+YQuick Access Toolbar (curved arrow right)
✅
Did you know?
Excel keeps up to 100 undo actions in memory — and this history persists even after you save the file. So if you save and then realize you made a mistake 30 steps ago, you can still use Ctrl+Z to go back. That said, undoing many steps means losing a lot of recent work, so it's usually better to make a targeted edit instead.
⚙

Topic 2: Save Workbooks

Saving, Save As, file formats, PDF export, and version conversion

0 of 4 sections read0%
All sections read!
🔒 Complete all sections to unlock the quiz

Saving your work is one of the most important habits to develop in Excel. If you close the program or lose power without saving, any unsaved changes are gone. Get into the habit of saving frequently using Ctrl+S.

Before saving, think about where you want to save it. Online locations (like OneDrive or SharePoint) are useful for collaboration and allow version history. Local saves (on your PC) are faster and work without internet.

Save a new workbook for the first time

1
Go to File > Save, or press Ctrl+S. Since this is a new file, Excel will prompt you to choose a location and name.
2
Check the location/folder where you want to store the workbook. You can save to This PC, OneDrive, or another connected location.
3
Enter an appropriate filename that clearly describes the file's contents, then click Save.

Save an existing workbook

Once a workbook has been saved once, saving again is instant:

  • Press Ctrl+S — saves immediately with no dialog
  • Go to File > Save
  • Click the Save button on the Quick Access Toolbar (the floppy disk icon)
✅
AutoSave
If your workbook is stored on OneDrive or SharePoint, AutoSave will appear in the top-left corner of Excel. When turned on, Excel saves your changes automatically every few seconds. This is one of the best reasons to store files in the cloud — you essentially never lose work.
💡
Did you know?
A workbook filename can contain up to 218 characters total — but this includes the full file path (all the folder names). If your file is stored deep in nested folders, you have fewer characters available for the filename itself.

Save As is used when you want to save the workbook with a new name, to a different location, or in a different file format. It creates a new file and leaves the original untouched.

How to use Save As

1
Go to File > Save As, or press F12. The Save As screen opens in Backstage view.
2
Choose the location/folder to save in. Options include This PC, a recent folder, Browse (for the classic dialog), or an online location like OneDrive.
3
Enter the new filename if changing it.
4
To save in a different format, click the Save as type dropdown and select the format you need.
5
Click Save.

Common file formats

FormatExtensionWhen to use it
Excel Workbook.xlsxStandard format for all modern Excel versions (2007 and later) — use this by default
Excel 97-2003 Workbook.xlsSharing with someone using an older version of Excel
Excel Template.xltxCreating a reusable template that others can fill in without overwriting the original
CSV (Comma Separated).csvExporting data to use in another application or database
PDF.pdfSharing a read-only version that looks the same on any device (covered in Section 03)
⚠
Compatibility mode
When you open an older .xls file, Excel runs in Compatibility Mode, which disables newer features like modern chart types, sparklines, and slicers. You'll see "[Compatibility Mode]" in the title bar. Use File > Convert to upgrade the file to the current format (covered in Section 04).

A PDF is a fixed-format file that looks identical on any device and cannot be easily edited. Saving your workbook as a PDF is ideal when you want to share data in a professional, print-ready format without worrying about the recipient having Excel installed.

Export to PDF using File > Export

1
Go to File > Export, then click Create PDF/XPS.
2
Check the location and edit the filename if needed.
3
Click Publish. Excel exports the currently active worksheets as a PDF file.

If you want more control over what gets exported, click Options before publishing. This lets you:

  • Choose a specific page range to export
  • Choose whether to export the entire workbook or just the active sheets
  • Remove document properties (author name, etc.) for privacy
  • Ignore defined print areas if needed
✅
Alternative: Save As PDF
You can also go to File > Save As, choose a location, and select PDF from the file type dropdown. This is a quick alternative that gives you slightly less control than the Export method but works well for simple single-sheet exports.
⭐
Cloud version history
If your workbook is saved to a cloud location like SharePoint or OneDrive and someone makes a mess of it, you can restore a previous version at any time. Go to File > Info > Version History to see and restore earlier versions. This is one of the most powerful reasons to work in the cloud.

Convert a workbook to the current format

When you open a workbook saved in the Excel 97-2003 format (.xls), Excel runs in Compatibility Mode. You'll see this in the title bar. In this mode, many modern Excel features are disabled or grayed out — including newer chart types, sparklines, slicers, and timeline features in PivotTables.

To upgrade an old workbook to the current format:

1
Go to File > Convert. A confirmation message will appear.
2
Click Yes to proceed. Excel converts the file to .xlsx format and closes the old file.
⚠
Before converting
Make sure the people you share the file with have a version of Excel that supports .xlsx (Excel 2007 or newer). If they're using a very old version, keep the .xls format. Conversion is a one-way process — the old .xls file will be replaced.
