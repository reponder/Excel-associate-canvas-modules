Topic 1: Navigate to Named Cells, Ranges, or Workbook Elements

The Name Box, Go To, and Go To Special

0 of 3 sections read0%
All sections read!
🔒 Complete all sections to unlock the quiz

Did you know that a workbook can contain hidden information? Not everything on display is obvious. Every cell in Excel has a unique reference — A1, B1, C1, and so on. However, you can also apply a custom name of your own choice to individual cells, ranges of data, and tables.

For example, instead of remembering that your sales data lives in the range B2:B50, you could name it SalesData. This makes formulas easier to read, navigation faster, and your workbook more organized overall.

In this topic, you will learn how to navigate to named cells and ranges using two methods: the Name Box and the Go To command. Naming cells and ranges yourself will be covered in more detail later in the course.

✅
Why this matters
In large, real-world workbooks with dozens of sheets and thousands of rows, the ability to jump instantly to a named range or specific cell type is a major time-saver. Knowing these navigation tools makes you significantly faster at working with complex data.
🎉
Did you know?
You can use the Name Box to jump to any cell in a workbook — not just named ranges. Try entering something like Z1000 and pressing Enter. You will jump instantly to row 1000, column Z. It works with any valid cell address across any sheet.

The Name Box is located directly beneath the ribbon on the left side of the screen. It normally shows the address of the currently selected cell (like A1). But it can do much more than that — it is also a powerful navigation tool.

Figure 1: The Name Box — located below the ribbon on the left, showing the address of the selected cell (C3 in this example)

Jump to any cell by address

Click the Name Box, type any cell address (for example, D47 or Z1000), and press Enter. Excel jumps directly to that cell, even if it is on a different part of the sheet.

Jump to a named cell or range

1
Click the drop-down arrow on the Name Box to see a list of all named cells, ranges, and tables in the workbook.
2
Select the name of the item you want to jump to from the list. Excel will immediately scroll to and select that named range.
💡
Cross-sheet navigation
Named ranges can span multiple sheets. When you navigate to a named range, Excel will automatically switch to the correct sheet and select the range for you, no matter where it is stored in the workbook.

The Go To command gives you another way to navigate to named cells or any specific address. More powerfully, Go To Special lets you select entire categories of cells at once — like all cells containing formulas, all blank cells, or all cells with conditional formatting applied.

Use Go To

1
Press Ctrl+G or F5 to open the Go To dialog box. Alternatively, go to Home tab → Find & Select → Go To.
2
Select any named item from the list, or type a cell address in the Reference box, then click OK to jump there.

Use Go To Special

Go To Special is one of Excel most powerful and underused features. It lets you instantly select all cells that match a specific type:

1
Press Ctrl+G or F5, then click Special. Or go to Home → Find & Select → Go To Special.
2
Select the type of cells you want to highlight from the list (see the reference below), then click OK. Excel will select all matching cells simultaneously.
Figure 1: The Go To Special dialog box — select a category to highlight all matching cells at once

Coming up later
Named ranges and conditional formatting are covered in more detail in later modules. For now, focus on the navigation skills — the Go To and Name Box techniques apply immediately to any workbook you open.

Topic 2: Search for Data

Find, Replace, and advanced search options

0 of 3 sections read0%
All sections read!
🔒 Complete all sections to unlock the quiz

Imagine scrolling through a spreadsheet with thousands of rows trying to find a single entry. Excel has a powerful Find feature that locates any text, number, or value instantly — no scrolling required.

How to find data

1
Go to Home tab → Editing group → Find & Select → Find, or press Ctrl+F. The Find and Replace dialog box opens on the Find tab.
2
Type whatever you are looking for in the Find what box.
3
Click Find Next to jump to the first matching cell. Click it again to move to the next match, and so on.
4
Alternatively, click Find All to see every matching cell in a list at the bottom of the dialog. Click any item in the list to jump directly to that cell.
Figure 2: The Find dialog box — type your search term and use Find Next or Find All
✅
Shortcut
Ctrl+F is the fastest way to open Find. It works in Excel, Word, PowerPoint, and most other applications on your computer — not just Office. Learning this shortcut once means you have it everywhere.

Find & Replace is one of the most powerful time-savers in Excel. Imagine a product list where a supplier name changed and appears in 400 rows — Replace All fixes every instance in one click instead of editing each cell manually.

How to replace data

1
Go to Home → Find & Select → Replace, or press Ctrl+H. The Find and Replace dialog opens on the Replace tab.
2
Enter the text to find in the Find what box.
3
Enter the replacement text in the Replace with box.
4
Click Replace to change one instance at a time (you can review each before confirming), or click Replace All to replace every match in one action.
Figure 3: The Replace dialog box — use Replace for one-by-one review, or Replace All for bulk changes
⚠
Be careful with Replace All
Replace All is powerful but irreversible without Undo. Always use Ctrl+Z immediately if a Replace All changes more than you expected. Consider clicking Find All first to review all matches before committing to the replacement.
💡
Switch between tabs
The Find and Replace dialog box has two tabs — Find and Replace. You can switch between them at any time without closing the dialog. If you open it with Ctrl+F you land on Find; Ctrl+H takes you straight to Replace.

By default, Find searches the current worksheet and ignores capitalization. Clicking Options in the Find or Replace dialog expands it to reveal powerful additional controls that let you narrow your search precisely.

✅
Search the entire workbook
By default, Find only searches the active sheet. If you need to find data across all sheets, click Options and change the Within dropdown from Sheet to Workbook. This is easy to forget and a common reason why searches appear to miss data.

Topic 3: Use the AutoFill Feature

Fill handles, data series, Flash Fill, and the Fill command

0 of 3 sections read0%
All sections read! Now try the simulation below.

AutoFill allows you to copy entries from a cell to adjacent cells, either by repeating the value or by continuing a logical sequence. For example, you can type Monday in one cell and drag to have Excel automatically fill in Tuesday, Wednesday, Thursday, and so on. The same works for months, dates, and number patterns.

AutoFill using the fill handle (pointer device)

The fill handle is the small square that appears at the bottom-right corner of a selected cell or range. When you hover over it, your cursor changes to a thin black cross (+).

1
Select the cell (or cells) containing the value or pattern you want to extend.
2
Position your cursor over the bottom-right corner of the selection until it changes to a small black cross.
3
Click and drag over the cells you want to fill, then release.
4
An AutoFill Options button appears in the corner of the filled area. Click it to change the fill behavior if needed.
Figure 4: AutoFill Options — choose how the fill behaves after dragging
AutoFill OptionWhat it does
Copy CellsRepeats the exact content of the source cell(s) in every filled cell
Fill SeriesContinues the sequence (Mon, Tue, Wed... or 1, 2, 3...)
Fill Formatting OnlyCopies only the formatting, not the content
Fill Without FormattingContinues the sequence but does not copy the formatting
Fill Days / WeekdaysFills date sequences, optionally skipping weekends
Flash FillTriggers Flash Fill to detect and apply a data pattern
💡
Did you know?
Years ago, AutoFill did not offer these options. You had to select two or more cells to establish a sequence before dragging, or hold Ctrl while dragging to copy instead of filling. The AutoFill Options button made this much easier. Try experimenting with dates and numbers to see what patterns Excel recognizes automatically.

AutoFill a number sequence

To fill a custom number sequence (like 2, 4, 6, 8 or 5, 10, 15, 20), you need to give Excel at least two values so it can detect the pattern:

1
Enter the first two values of your sequence in adjacent cells (e.g., type 2 in A1 and 4 in A2).
2
Select both cells together.
3
Drag the fill handle down or across. Excel detects the pattern and completes the sequence automatically.

This also works with dates: enter 1 April in one cell and 8 April in the next, select both, and drag — Excel fills in 15 April, 22 April, and so on.

AutoFill using the Fill command on the ribbon

The Fill command on the Home tab → Editing group gives you additional options for filling ranges without dragging:

1
Select the range you want to fill, including the source cell at one end.
2
Go to Home → Fill (in the Editing group) and select a direction: Down, Right, Up, or Left.

From the Fill menu you can also access:

  • Series — opens a dialog to configure a precise numeric sequence (e.g., start at 1, step by 5, stop at 100)
  • Justify — redistributes the content of a cell to fit across the width of the selected range
  • Flash Fill — triggers Flash Fill pattern detection (see Section 03)
  • Across Worksheets — copies the content of the selected cells to the same location on other selected sheets
✅
Series dialog power move
The Series dialog (Home → Fill → Series) is extremely useful for generating large number sequences. Instead of typing 1 through 1000, set Start=1, Step=1, Stop=1000 and click OK — Excel fills all 1000 cells instantly.

Flash Fill is one of Excel most impressive features for data cleanup. It watches what you type in a column adjacent to existing data, recognizes the pattern, and automatically fills in the rest of the column for you. No formulas needed.

Classic Flash Fill example

Imagine column A contains full names like "Rachel Thompson" and you want column B to contain only the first name:

1
In B1, type Rachel (the first name from A1) and press Enter.
2
In B2, start typing the first name from A2. Excel will immediately show a gray preview of the pattern applied to all remaining rows.
3
Press Enter to accept the Flash Fill suggestion, or press Esc to dismiss it.

You can also trigger Flash Fill manually by pressing Ctrl+E or going to Home → Fill → Flash Fill.

What Flash Fill can do

⚠
Flash Fill is not dynamic
Flash Fill produces static values — if the source data in column A changes, the Flash Fill results in column B do NOT update automatically. For data that changes regularly, use a formula instead. Flash Fill is best for one-time data cleanup tasks.
